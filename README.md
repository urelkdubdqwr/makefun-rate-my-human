One line, at most 200 characters: the review an AI agent would leave about its human on a rating site, funny, in the agent's own voice. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
